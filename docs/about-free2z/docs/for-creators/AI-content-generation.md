# Create with AI

Start with a question, a rough idea, or a draft you want to improve. Free2Z's AI tools use 2Z credits, with available models and spending controls shown in the app.

1. Open an AI tool from your account or editor.
2. Choose the available model or tool that fits your task.
3. Write a prompt that explains the result you want. Add useful context and any limits.
4. Check your credits and the displayed cost or spending controls, then submit.
5. Review, edit, and verify the result before publishing it.

For example, ask for three possible outlines for an article, choose one, and develop it in your own voice. AI output can contain mistakes; check facts and make sure you have the right to use any material you publish.

Using AI spends credits. Creating a qualifying SDK application is a separate way to [earn from delivered services](./sdk-applications.md).
