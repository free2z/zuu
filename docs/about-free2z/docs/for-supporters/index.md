# Explore, join, and support

Find an interesting page, a live conversation, or a creator you want to follow. Use 2Z credits for platform experiences, or send Zcash directly to a creator's wallet.

| What you want to do | Where to start |
| --- | --- |
| Give someone platform credits | [Share 2Zs](./donating-with-2Zs.md) |
| Join a creator's membership | [Subscribe](./subscriptions.md) |
| Watch a live room | [Livestream access](./free2z-live.md) |
| Send support from your wallet | [Direct Zcash support](./donating-with-zcash.md) |

Comments, votes, boosts, and paid access use the credits shown for each action. [Buy credits with Zcash](../getting-started/03-tuzis.md) in Credits & Earnings when you need more.

Sharing credits and subscribing provide utility credits and membership benefits. They do not create USD earnings. Qualifying delivered PPV and SDK services are the separate [creator earnings program](../revenue-sharing/index.md).
