# Watch a livestream

Join a conversation, watch a broadcast, or attend a creator's pay-per-view room. Open the creator's profile or the link they share, then check the access type.

| Room | What you need |
| --- | --- |
| Public broadcast | The public room link; some broadcasts allow watching without an account |
| Subscriber-only | An active membership with the creator |
| Pay-per-view | A signed-in account and credits for the displayed price per minute |
| Private | The invitation link supplied by the host |

For pay-per-view, check the rate and your available credits before joining. Leave the room when you are finished watching.

Use the room's chat, microphone, camera, and leave controls as needed. Grant device permissions only for the features you want to use. [Buy more credits](../getting-started/03-tuzis.md) in Credits & Earnings, or [learn about memberships](./subscriptions.md).
