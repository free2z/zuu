# Go live (host)

Start a Free2Z Live stream for a public audience, subscribers, pay-per-view viewers, or a private invite.

Only you can start a stream on your own account.

## Requirement

Hosting requires at least **150 2Z usage credits**. This is a platform usage requirement, not a verification or earnings threshold. If you don’t qualify yet, the app shows a clear message.

## Steps

### 1. Open stream controls

Any of these work:

- Dashboard → **Start Live Stream**  
- **My Pages** → **Go Live**  
- Creator tools → **Stream**  

### 2. Optional: settings

Click **Settings** if you want to:

| Setting | Options |
| --- | --- |
| **Video quality** | 360p, 480p, 720p (default), 1080p |
| **Audio test** | Quick mic check before you go live |

### 3. Choose stream type

| Type | Who can watch | Notes |
| --- | --- | --- |
| **Broadcast** | Anyone, free | Host cost may show as about **1 Tuzi / 2 min per viewer** |
| **Subscribers** | Monthly supporters only | Exclusive for members |
| **Pay Per View** | Anyone who pays | You set a **price per minute** in Tuzis |
| **Private** | People with your secret link | Good for 1-on-1 or invite-only |

### 4. Pay-per-view price (if needed)

1. Select **Pay Per View**  
2. Enter **Price per Minute (Tuzis)**  

### 5. Start

1. Click the start / go live control  
2. Allow camera and microphone when the browser asks  
3. Wait for the stream to start  
4. You’ll see a success message when you’re live  

### 6. Private streams

If you chose **Private**:

1. Free2Z creates a secret invite link  
2. The link is copied when possible  
3. You’re taken into that private room  
4. Share the link only with people you trust  

### 7. While you’re live

- Viewer count updates as people join  
- If your connection drops, you may see a **Connection Lost** message  
- Leaving the page while live may warn you that the stream is still active  

## Share your stream

For public types, share your normal live link or profile. For private, share only the secret invite link.

When you’re live, a **Live** indicator may show in the app.

## End the stream

Use the leave / end controls in the live room. When the session ends, you’ll return to your creator tools.

For compensated pay-per-view, complete payee verification, accept the creator agreement and service terms, and confirm Credits & Earnings shows you are ready for creator compensation before offering the room. Qualifying delivered access earns separate USD compensation. Subscriber rooms use membership access. [Learn about creator earnings](/revenue-sharing/).
