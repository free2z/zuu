# Private streams

Private streams use a **secret invite link**. They are not listed on the public live page.

## Host: create one

1. Open **Stream** in your creator tools  
2. Select **Private**  
3. Start the stream  
4. Copy the secret link when Free2Z offers it (or grab it from the next screen)  
5. You’re in the room as host  

## Guest: join

1. Open the exact secret link the host sent you  
2. The private room opens  
3. This room does not appear as a public live stream  

## Safety tips

- Treat the secret link like a password  
- Don’t post private links in public places  
- Start a new private session if you need a fresh link
