# Watch a livestream

## Find a live creator

- A **Live** badge on their profile or in the app  
- A link they share with you  
- A choice screen if they have more than one kind of stream running  

## Steps

1. Open the creator’s live link or profile live entry  
2. If access is allowed, the live room opens  
3. Watch, chat, and join in based on what the host allows  

## Access by stream type

| Type | If you can’t get in |
| --- | --- |
| **Broadcast** | Usually open to everyone |
| **Subscribers-only** | You’ll be asked to [subscribe](/guides/support/subscribe) |
| **Pay Per View** | You’ll be asked to pay (often with 2Zs) and may need to sign in |
| **Private** | You need the secret invite link — see [Private streams](/guides/live/private-stream) |

## Payment or subscribe prompts

- **Subscribe** — when the stream is for members only  
- **Pay Per View** — when you need to pay per minute; you may be sent to **Buy 2Z** or **Log in**  

## Connection issues

- An offline banner if your network drops  
- Automatic retries a few times  
- A message when the stream ends  

## More than one stream type

If the creator is running more than one kind of stream, pick the option you want from the list and join that room.
