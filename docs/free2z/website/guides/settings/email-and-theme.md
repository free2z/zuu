# Email & appearance

Open **Settings → Account**.

## Email

### Add or update email

1. Enter your address  
2. Save / update  
3. Free2Z may ask you to confirm it  
4. Check your inbox; resend if needed  

### Status

| State | Meaning |
| --- | --- |
| Confirmed | Verified email on file |
| Pending | Waiting for you to confirm |
| Public toggle | Whether the email is shown publicly |
| Notifications toggle | Email notifications on or off |

### Remove email

Use the delete control if you want it removed.

## Theme / appearance

Choose:

| Option | Behavior |
| --- | --- |
| **Light** | Always light |
| **Dark** | Always dark |
| **System** | Match your device |

Both modes use Free2Z’s usual colors and layout.
