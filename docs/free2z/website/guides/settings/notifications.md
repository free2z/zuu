# Notifications

## Open

1. Sign in  
2. Click the **bell** in the top bar (on larger screens)  
3. Or open **Notifications** from your creator tools  

An unread count may show on the bell (up to 99+).

## What you’ll see

A scrolling list of activity, such as:

| Kind of event | What it means |
| --- | --- |
| Donation in / out | Tips you received or sent |
| Subscription in / out | New members or subscriptions you started |
| Comment / reply | Someone commented or replied |
| Page vote / update | Activity on a page |
| Bought 2Zs | You topped up credits |
| Live usage activity | Credits spent on livestream time and access; check Credits & Earnings for separate USD earnings |
| Platform fee | Fees related to activity |

Each row can show who was involved, an amount, and how long ago it happened.

## Filters

Toggle between:

- **Social** — social-style activity  
- **All** — everything  

## Interact

1. Click an event — unread items mark as read  
2. If the event has a related page or profile, you’ll go there  

## Mark all / refresh

Use the on-screen controls to refresh or mark everything as read when those buttons are shown.
