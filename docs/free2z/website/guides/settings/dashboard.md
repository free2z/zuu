# Creator dashboard overview

Your dashboard is the home base after you click your **picture** → **Profile**.

## At a glance

### Stats

You may see cards for:

- How many pages you’ve **published**
- How many **drafts** you have
- **2Z usage credits**
- **Fans** who support you

### Quick actions

| Button | What it does |
| --- | --- |
| **Create New Article** | Opens the editor for a new page |
| **Start Live Stream** | Opens live streaming controls |
| **Upload Media** | Opens your media library |

### Quick Upload

A simple drop zone for fast uploads without leaving the dashboard.

### Your bio card

Shows your description, whether a Zcash address is set, and your membership price (if any).

### Recent drafts and published pages

Jump straight into edit or view for recent work.

### Header actions

- **Public View** — see your profile as visitors do  
- **Edit Profile** — open settings to change avatar, bio, and more  

## Other creator tools

From the same area you can usually reach:

| Area | What it’s for |
| --- | --- |
| **Pages** | Drafts and published zPages |
| **Media** | Uploads library |
| **Stream** | Go live |
| **Notifications** | Alerts and activity |
| **Credits** | 2Z balance and purchases |
| **Settings** | Account, email, security, theme |
