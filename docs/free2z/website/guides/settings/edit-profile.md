# Edit profile

Update how you look and how people can support you.

## How to open

Any of these work:

- Your **picture** → **Settings**  
- Your public profile (when it’s you) → **Settings**  
- Dashboard → **Edit Profile**  

## What you can change

| Field | Notes |
| --- | --- |
| **Full name** | Display name people see |
| **Description / bio** | About you on your public profile |
| **Zcash address** | Where people send Zcash tips |
| **Membership price** | Monthly subscription price in 2Zs |
| **Avatar** | Profile picture |
| **Banner** | Cover image at the top of your profile |

## Image rules

- Formats: **JPEG, PNG, WEBP, GIF**  
- Max size: about **5 MB**  

## Steps

1. Open **Settings**  
2. Stay on the **Profile** tab  
3. Edit the text fields  
4. Click the avatar or banner controls to pick images (preview updates right away)  
5. Click **Save**  
6. Success: **Profile updated successfully.**  

## Check the public view

Open **Public View** to confirm banner, avatar, bio, and buttons look right.

## Membership price

Setting a membership price lets others [subscribe](/guides/support/subscribe) to you. Leave it empty or free if you don’t want paid membership.
