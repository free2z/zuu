# Search articles

Find zPages by topic, title, or keywords.

## Steps

### From any page

1. Click the search field in the top bar (“Find something…”)  
2. Type what you’re looking for  
3. Press **Enter**  

### On the search results page

1. Change the text in the search box if you want  
2. Click **Search** or press Enter  
3. Browse the result cards  
4. Click a result to open the page  

## Helpful details

- Results are split across pages when there are many matches  
- Recent searches may appear so you can try them again  
- If nothing matches, try different words or a simpler phrase  

## Tips

- Browse people separately on [Browse creators](/guides/discover/browse-creators)  
- Use distinctive title words or topics  
- Clear recent searches with the control on the page when it’s shown
