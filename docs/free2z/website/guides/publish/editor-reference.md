# Editor reference

A quick map of the Free2Z writing editor — what each control does.

## Top bar

| Control | What it does |
| --- | --- |
| **X** | Leave the editor and go to **My Pages** |
| **Add / Remove Cover** | Show or hide the cover image field |
| **Add / Remove Subtitle** | Show or hide the short summary field |
| **Save status** | Idle, Saving, Saved, or Error |
| **Publish / Update** | Make the page public, or save changes to a published page |
| **Write / Split / Preview** | Choose how you write and preview |
| **Settings (gear)** | Categories, custom link name, subscribers-only, and more |

## Type `/` for shortcuts

| Shortcut | What you get |
| --- | --- |
| Heading 1–3 | Big, medium, or small headings |
| Bold | **Bold text** |
| Italic | *Italic text* |
| Code block | A block for code or plain text samples |
| Quote | An indented quote |
| Bullet list | A list with dots |
| Numbered list | A numbered list |
| Link | A clickable link |
| Image | An image from a link |
| Table | A starter table |
| Divider | A horizontal line |

Use the keyboard to move through the menu, then confirm to insert.

## Page settings (gear)

You can set:

- **Title** and **body** (required)
- **Description** / subtitle (optional)
- **Categories** (optional)
- **Custom link name** (recommended so people can find your page)
- **Published** or still a draft
- **Subscribers only**

## Categories

Examples include: Art, Comedy, Community, Charity, Education, Fiction, Fundraising, Gaming, Health, Lifestyle, Math, Music, Podcast, Politics, Relief, and more.

## Common problems

- **Title required** — add a title before saving
- **Content required** — write something in the body
- **Link name taken or invalid** — try a different custom link name

## Autosave

- Saves about **2 seconds** after you stop typing
- Won’t start another save if one is already running
- You need to stay signed in while you write

## Tips for longer posts

1. Keep it as a draft until the title and cover feel right  
2. Use **Split** mode to check formatting as you go  
3. Set a custom link name before you share the page  
4. Use **Subscribers only** for posts meant for paying members — after you set a [membership price](/guides/settings/edit-profile)
