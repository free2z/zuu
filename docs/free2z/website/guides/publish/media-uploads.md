# Upload media

Upload images and other files for your profile, covers, and zPages.

## Where to upload

- **Media** in your creator tools — full media library  
- **Quick Upload** on your dashboard — fast uploads while you work  

## Upload files

### Drag and drop

1. Open **Media** or **Quick Upload**  
2. Drag files onto the drop area  
3. Wait while each file moves through: queued → uploading → processing → done  

### Choose files

Click the upload area and pick one or more files from your device.

You’ll get a short success or error message for each file.

## Profile photos

Avatar and banner images are uploaded from **Settings** (profile tab).

Typical limits:

- Types: JPEG, PNG, WEBP, GIF  
- Max size: about **5 MB**  

See [Edit profile](/guides/settings/edit-profile).

## Use media in a zPage

1. Upload the file and copy its link (or keep it handy)  
2. In the editor, type **/** and choose **Image**, or paste the image link  
3. Or set a cover image at the top of the editor  

## Who can open a file?

Depending on the upload options available:

| Access | Who can open it |
| --- | --- |
| **Public** | Anyone with the link |
| **Private** | Mainly you |
| **Members-only** | Your subscribers |

::: warning
“Private” is not a locked vault. Don’t upload anything illegal or that you wouldn’t want mishandled.
:::
