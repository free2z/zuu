# Two-step verification

Two-step verification adds a code from your phone after your password. You manage it under **Settings → Security**. You need a password on the account before you can turn it on.

## Turn it on

1. Sign in  
2. Click your **picture** → **Settings**  
3. Open the **Security** tab  
4. Start **setup** for two-step verification  
5. Scan the **QR code** with an authenticator app (or copy the secret key if you prefer)  
6. Enter the **6-digit code** from the app  
7. Confirm **Enable**  

When it works, Settings will show that two-step verification is on.

## Log in with two-step verification

1. Enter username and password as usual  
2. When prompted, enter the current 6-digit code from your app  
3. Click **Verify**  

## Turn it off or manage it

1. **Settings** → **Security**  
2. Open the two-step verification options  
3. Follow the steps to disable (you’ll need to confirm)

## Troubleshooting

| Issue | What to try |
| --- | --- |
| Asked to set a password first | [Set a password](/guides/account/change-password), then try again |
| Code rejected | Make sure your phone’s time is automatic; try the next code |
| Lost your authenticator | Use any recovery option Free2Z offers, or contact support if you’re locked out |
