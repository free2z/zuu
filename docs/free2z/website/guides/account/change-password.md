# Change or set password

## Where

**Your picture → Settings → Security**

## If you already have a password

1. Enter **Current password**  
2. Enter **New password**  
3. **Confirm** the new password  
4. Save  

## If no password is set yet

Some accounts (for example, ones that only used social sign-in) may not have a password yet:

1. Enter **New password**  
2. Confirm it  
3. Save (current password isn’t needed)

## Rules

- New password and confirm must match  
- Don’t leave the new password blank  

Success message: **Password updated successfully.**
