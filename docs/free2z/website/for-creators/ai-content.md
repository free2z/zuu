# Create with AI

Bring an idea, a question, or a rough draft. Free2Z’s AI tools help you explore and create using 2Z credits. Pick a tool and review its cost before starting.

1. Open an AI tool from your account or editor.
2. Write a clear prompt and check the available credits and spending controls.
3. Submit the request and review the result.
4. Edit and verify the output before publishing it.

Make the result yours: edit it, check the facts, and make sure you have the rights to publish it. Want to build an AI-powered application? [Explore the SDK](/for-creators/sdk-applications).
