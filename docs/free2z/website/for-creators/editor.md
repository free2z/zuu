# Markdown Editor

The Free2Z editor is a focused place to write zPages.

Open it with **Write**, **Create**, or **Edit** on one of your pages.

## Modes

| Mode | Use |
| --- | --- |
| **Write** | Quiet writing space |
| **Preview** | How readers will see it |
| **Split** | Write and preview side by side |

## Core fields

- **Title** — required  
- **Subtitle / description** — optional supporting line  
- **Cover image** — optional; strongly recommended for cards  
- **Body** — your main content  

## Type `/` for shortcuts

In the body, type **/** for quick inserts:

- Headings  
- Bold / italic  
- Code block  
- Quote  
- Bullet / numbered lists  
- Link / image  
- Table  
- Divider  

::: tip
Shortcuts are the fastest way to structure a draft without leaving the keyboard.
:::

## Page settings

Use the gear / **settings** panel for:

- Categories  
- Custom link name  
- Visibility (public / subscribers)  
- Scheduling (when available)  
- Donation address overrides  

This is the single place for non-body page settings.

## Saving and staying signed in

- You must be signed in to create or edit  
- If you get signed out, log in again and save  
- You’ll see **Saving… / Saved / error** while you work  

## Embeds and advanced formatting

You can embed outside media and use richer formatting when you need it. Prefer your own uploads for sensitive material.

## Outside content and privacy

When a page includes content from other sites, Free2Z may warn readers before loading it. That protects privacy — outside sites can see some browser information when their content loads.
