# Get started

Browse public pages, then create an account when you want to publish or use account services.

1. [Create your account](/getting-started/quickstart).
2. [Set up your public profile](/getting-started/profile).
3. [Publish a zPage](/getting-started/zpages).
4. [Understand usage credits](/getting-started/tuzis) before buying or spending them.

You can publish without a Zcash wallet. A wallet is optional for Zcash payments or direct support. Store your password securely; an optional email enables email recovery.
