# Navigating the App

Free2Z is organized around reading, discovery, and creation.

## Top bar

| Control | Purpose |
| --- | --- |
| **Free2Z** logo | Home |
| **Search** | Find articles, creators, and topics |
| **Creators** | Browse people on Free2Z |
| **Write / Create** | Open the writing editor |
| **Notifications** | Your activity feed |
| **Sign in / your picture** | Sign in, or open your account menu |
| **Theme** | Light or dark appearance |

The top bar stays handy while you scroll — it may hide as you scroll down and return when you scroll up.

## Home

The homepage highlights:

1. **Featured story** — a large highlighted zPage
2. **Trending** — rising pages
3. **Popular** — widely read posts
4. **Creator spotlight** — people to follow
5. **Topics** — themes and categories
6. **Get started** — prompts to join or publish

## Profiles

Each creator has a public profile (for example `free2z.com/yourname`).

From a profile you can:

- Read their zPages
- **Subscribe** with 2Zs
- **Support → Zcash** (if they set an address)
- See when they’re live

## zPages

Published pages are the articles and posts you read and share.

On a page you can boost, send support, share, and comment.

## Creator tools

When you’re signed in, open your picture menu or profile for:

| Section | Use |
| --- | --- |
| **Pages** | Drafts and published zPages |
| **Profile** | Your public profile and overview |
| **Media** | Uploads library |
| **Stream** | Go live |
| **Notifications** | Alerts |
| **Credits** | Credits, purchases, creator earnings, and payment requests |
| **Settings** | Account and security |

## Live

Open a creator’s live stream from their profile, a shared link, or the live indicator when they’re on air.

The host chooses whether the stream is open to everyone, members-only, pay-per-view, or private.

## Writing shortcuts

In the editor, type **/** for quick inserts (headings, lists, quotes, images, and more).
