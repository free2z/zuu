# Subscribe to a creator

Keep up with a creator you love. A membership uses 2Z credits and can unlock subscriber-only pages and livestreams; check the creator’s offer to see what’s included.

1. Open the creator's profile and select Subscribe.
2. Review the monthly credit price, available balance, and confirmation details.
3. Confirm only if you want those membership benefits.
4. Manage or cancel the subscription from Credits & Earnings. Check the displayed renewal and access dates.

Creators can set their membership price in profile settings. Memberships provide platform access and benefits using credits; they do not create USD earnings.
