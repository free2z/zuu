# Discover Creators

## Home feed

On the homepage you’ll find:

- Featured story
- Trending zPages
- Popular zPages
- Creator spotlight
- Topic chips from tags and categories

## Creators directory

Open **Creators** to browse public creators with filters.

## Search

Use the search field in the top bar to find:

- Articles
- Creators
- Topics

## Profiles

Open a creator’s profile to:

- Browse their pages
- Subscribe
- Send Zcash support
- Jump into live when the indicator is on

## Following great work

There’s no need to “like and hope.” If something is excellent:

1. **Boost** it
2. **Comment** thoughtfully
3. **Subscribe** if you want more
4. **Share** the link
