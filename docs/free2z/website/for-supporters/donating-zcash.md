# Send direct Zcash support

Send a thank-you straight to a creator’s wallet. Direct Zcash support uses their displayed receiving address, while [sharing 2Zs](/for-supporters/donating-2zs) helps them use the platform.

1. Open the creator’s profile or page and choose **Support → Zcash**. Enter an amount and, when supported, add or edit the memo.
2. Verify the recipient address, amount, and any memo in your wallet.
3. Check your wallet's fees and privacy behavior before sending.
4. Keep the transaction record if you need to discuss the transfer with its recipient.

The creator controls the receiving wallet. A public support address is not the company's payout destination.
