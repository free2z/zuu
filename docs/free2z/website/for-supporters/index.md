# Use and share 2Zs

Find a creator or page you want to read, watch, or support. Usage credits pay for platform services; direct Zcash support goes to a creator's wallet.

| Action | What it does |
| --- | --- |
| Share 2Zs | Lets another user use platform services |
| Subscribe | Uses credits for a creator's membership benefits |
| Watch pay-per-view | Uses credits at the room's displayed price |
| Boost, comment, or vote | Uses the credits displayed for that action |
| Send direct Zcash | Transfers Zcash to the creator's own displayed wallet address |

[Understand usage credits](/getting-started/tuzis) before buying. [Learn about direct Zcash support](/for-supporters/donating-zcash) before sending.

Share credits to help someone keep creating. For company-paid compensation from qualifying livestreams or SDK services, read [Creator earnings](/revenue-sharing/).
