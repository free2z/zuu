# Cryptographic known-answer vector provenance

These files are test inputs copied or transcribed from standards publishers;
they are not outputs generated by the implementation under test.

## ML-KEM-768

`nist-acvp-ml-kem-768.json` contains three unmodified test cases selected from
the NIST ACVP-Server `internalProjection.json` files at commit
`975de31eb83d87039ec88934fdc47d8c312b892d`:

- key generation: `ML-KEM-keyGen-FIPS203`, group 2, tcId 26;
- encapsulation: `ML-KEM-encapDecap-FIPS203`, group 2, tcId 26;
- decapsulation: `ML-KEM-encapDecap-FIPS203`, group 5, tcId 86.

The only transformation was placing those three JSON objects beneath named
keys. Field names and hexadecimal values are unchanged. Authoritative sources:
[key generation](https://github.com/usnistgov/ACVP-Server/blob/975de31eb83d87039ec88934fdc47d8c312b892d/gen-val/json-files/ML-KEM-keyGen-FIPS203/internalProjection.json)
and [encapsulation/decapsulation](https://github.com/usnistgov/ACVP-Server/blob/975de31eb83d87039ec88934fdc47d8c312b892d/gen-val/json-files/ML-KEM-encapDecap-FIPS203/internalProjection.json).

## X25519 and Ed25519

`rfc-7748-x25519.json` transcribes the complete X25519 agreement vector from
[RFC 7748 section 6.1](https://www.rfc-editor.org/rfc/rfc7748.html#section-6.1).
`rfc-8032-ed25519.json` transcribes TEST 1 and TEST 2 from
[RFC 8032 section 7.1](https://www.rfc-editor.org/rfc/rfc8032.html#section-7.1).
Line wrapping and labels were removed; hexadecimal values are unchanged.

The X25519 all-zero refusal test uses a synthetic low-order public input, not a
transcribed vector. RFC 7748 permits implementations to test the shared secret
for all zeroes using a constant-time comparison; it does not require aborting.
Refusal is the stricter free2z acceptance policy, and libcrux performs the
comparison internally.

Both RFCs are copyright the IETF Trust and their named authors and are subject
to BCP 78 and the IETF Trust Legal Provisions in effect on their publication
dates. Those provisions govern these transcribed vectors; the surrounding test
harness remains MIT-licensed as declared by its Cargo manifest.
