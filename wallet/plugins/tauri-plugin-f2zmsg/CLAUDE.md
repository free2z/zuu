# CLAUDE.md — `tauri-plugin-f2zmsg`

Read [`README.md`](./README.md) for what this crate is and
[`docs/e2ee/CLIENT-CONTRACT.md`](../../../docs/e2ee/CLIENT-CONTRACT.md) for the
contract it implements. This file is the short list of things that will bite you.

Rust edition 2024, MSRV 1.97.

## Four things that are not style preferences

**1. Never ACK before the durable local write completes.** The relay deletes on
ACK. An ACK plus a crash is permanent message loss, from every copy that ever
existed. `Engine::pump_inbound` runs decrypt → commit → ACK → emit in that order,
and `engine.rs`'s module header explains the one window it cannot close. If you
are changing that function, read the header first.

**2. `on_event` handles `Exit`/`ExitRequested` and nothing else.** Do not copy
`tauri-plugin-zcash`'s blur handler. Tearing state down on
`WindowEvent::Focused(false)` would drop relay connections and stop
acknowledging inbound messages on every alt-tab.

**3. Enrollment does not belong here.** It needs the wallet seed, and the seed
must never cross IPC. Adding an enrollment command to `command_registry.rs`
fails `wallet/zuuli/scripts/messaging-contract.node-test.mjs`, which asserts the
absence rather than trusting it.

**4. Do not make the directory resolve.** `directory::NoDirectory` fails closed
with `witness-threshold-unmet` because §6.4 and §9 rule 5 say an unverified key
at first contact *is* the MITM. A permissive resolver "just for development" is
the defect those rules exist to prevent. The two-process harness substitutes the
resolution from outside the crate, which is why it is a test binary.

## Commands

```console
cargo +1.97.1 build --locked                       # the shipping configuration
cargo +1.97.1 test  --locked --features relay-harness   # incl. the two-process relay test
cargo +1.97.1 clippy --all-targets --all-features -- -D warnings
node ../../../scripts/check-tauri-plugin-permissions.mjs --self-test
node ../../../scripts/check-tauri-plugin-permissions.mjs
```

`permissions/` is generated by `build.rs` and **committed**. CI rebuilds it with
a fresh `TAURI_PERMISSION_GENERATION_NONCE` and rejects any diff or untracked
leftover, so a stale commit fails rather than drifts.

## Where the seams are

`envelope.rs` is the adapter over `f2z-msg-dag`; §7 is that crate's and no
longer this one's. `relay.rs` belongs in `rs/crates/f2z-relay-client` so the WASM client
can share it. `directory.rs` needs an HTTP client over `/kt/v1/lookup` and
`f2z_kt_core::verify`. Each says so at the top of the file, with what must not
change when it moves.
